# Assumptions

Every rule reading Loopwright depends on. The code reads the config flag; change a default only when the Answer column is filled from an authoritative source.

| ID | Question | Default | Config flag | Answer | Source | Date |
|----|----------|---------|-------------|--------|--------|------|
| Q1 | Must a zone's rooms be joined by doors between themselves, or may the link pass through a room of another zone (usually the living room)? | strict | `zone_link = "strict"` (also `"circulation"`, `"through_rooms"`) | | | |
| Q2 | What exactly is J: its terms and weights? | J = L + 0.3·B + 3·X + 2·O, in metres | `bend_m = 0.3`, `crossing_m = 3`, `overlap_factor = 2` | | | |
| Q3 | Does a turn at a node count as a bend? Are two parallel runs through one door an overlap? Do crossings within one ring count? | Turns at vertices, nodes and the hub are bends, a reversal once; crossings and overlap count inside and between rings, a stretch covered k times counting (k − 1) times its length; within 1 mm is the same point or line | `bend_at_node = true`, `tolerance_m = 0.001`, `count_self_crossings = true` | As the default | Organisers' slide 7, metric definitions | 2026-10-16 |
| Q4 | Is the cap 5 nodes per hub (deck) or 20 devices (written statement)? | 5 | `max_nodes = 5` | 5 | Eval-01 meeting | 2026-10-16 |
| Q5 | What does the organisers' JSON look like: keys, geometry encoding, units? Does it give node positions? | ResPlan keys; scale from area | `input_format = "auto"` | Test plans come from the ResPlan dataset itself; the output is the JSON and a drawing. Node positions are ours to choose | Eval-01 meeting | 2026-10-16 |
| Q6 | If node positions are ours to choose, is any fixed rule acceptable? | The point nearest the room's doors that keeps 0.5 m from its walls (the point farthest from the walls if the room has no opening) | `node_rule = "near_doors"` (also `"pole"`), `node_wall_m = 0.5` | Our choice, at least 0.5 m from the walls | Eval-01 meeting | 2026-10-16 |
| Q7 | Must a hub be on a wall? Is there a minimum distance between a hub and a node? | Anywhere inside an eligible room of its own zone, at least 0.5 m from every node of its ring | `hub_mount = "free"`, `min_hub_node_m = 0.5` | No fixed minimum, but not 0; a stated minimum is welcome | Eval-01 meeting | 2026-10-16 |
| Q8 | May cables pass through bathrooms, corridors, stairs and rooms of other zones? | Corridors and rooms of other zones, yes. Bathrooms and stairs only when no route avoids them, reported as `THROUGH_EXCLUDED` | `pass_through = ["circulation", "bathroom", "stair", "other_zones"]` (zone links); routing always tries without bathrooms and stairs first | Through excluded rooms only when it is the only way, with the reason given | Eval-01 meeting | 2026-10-16 |
| Q9 | When ResPlan draws the living room in pieces, is it one room? | One room (ResPlan's own convention; 231 plans). Where walls part the pieces, its one node goes in the piece that lets the zones use the fewest hubs, reported as `NODE_MOVED` (plans 1180, 8111) | `living_pieces = "merge"` | | | |
| Q10 | For angled walls, does "horizontal and vertical" mean the drawing's axes? | The drawing's axes | `axis_frame = "drawing"` | | | |
| Q11 | What should the output be when no valid design exists, for example a room over 100 m²? | Flag infeasible, plus a relaxed design marked invalid | `infeasible_output = "flag_and_relaxed"` | | | |
| Q12 | How are entries scored: hidden plans, totals, per plan, or the demo? Is there a time limit? | Optimise totals; keep p95 under 2 s per plan | `time_limit_s = 10` | | | |
| Q13 | May code written before the 48 hours start be used? | No | (process, not code) | | | |
| Q14 | For the 100 m² cap, is room area the polygon area × scale², or the dimensions in the organisers' JSON? | Polygon area × scale² | `area_source = "polygon"` | | | |
| Q16 | In about 1.5% of ResPlan plans the `inner` outline leaves out parts of rooms (plan 407696: 12 of the living room's 22 m²). Is everything inside the room outlines inside the building? | Yes: widen the outline to cover every room and door, and report `INNER_REPAIRED` | (always on) | | | |
| Q15 | Some rooms connect to the rest of the home only through an interior "window" (ResPlan's own tools treat these as misclassified doors). May cables pass through such a window, or is the room unreachable? | Unreachable: follow the rule literally and report it (about 2% of plans, e.g. 11160) | `interior_window = "block"` (planned: `"door"`) | | | |
| Q17 | How small may an eligible room be before it gets no node? | Under 2 m², or with no point 0.5 m from its walls: no node, reported as `ROOM_NEGLECTED` | `min_room_m2 = 2` | Very small rooms may be left out; about 2 m² suggested | Eval-01 meeting | 2026-10-16 |
| Q18 | ResPlan draws some doors shallower than the wall they sit in, which leaves a strip of wall a few centimetres thick across the doorway (plan 4755: 3 cm). Does such a door still open the whole wall? | Yes: a door opens the wall it is drawn in from face to face. Wall left within half a wall depth of a door's face, along at least 90% of its width, is doorway too; a wall that only meets the door's side is not. Solver and validator both read doors this way | (always on) | | | |
